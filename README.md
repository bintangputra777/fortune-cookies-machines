## The fortune

> You will soon meet a stranger: the code you wrote yesterday. It will not remember you, and neither will you.

## How it works

`main.ts` writes the single fortune line to `/output/entry.txt` (one line, within the 200-character limit).

Run it twice — the output is byte-identical every time:

```sh
node main.ts
```
